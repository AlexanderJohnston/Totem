# Backend Integration Guide

Use the `api/microfilm` endpoints for the frontend integration flow below. This backend follows a command/query split:

- `POST` and `PUT` endpoints change state and usually return status only.
- `GET` endpoints return projected JSON models.
- IDs are generated by the backend, so after a successful create call you should re-query to retrieve the new `serverId`, `clientId`, `boxId`, or `rollId`.

## Recommended flow

1. `GET /api/microfilm/servers` to list known servers.
2. If needed, `POST /api/microfilm/servers` to create a server.
3. `GET /api/microfilm/servers` again to retrieve the new `serverId`.
4. `POST /api/microfilm/clients` to create a client for that server.
5. `GET /api/microfilm/clients/{serverId}` to retrieve the new `clientId`.
6. `POST /api/microfilm/wasp/import/force` to refresh WASP boxes and rolls for all known clients.
7. Optionally poll `GET /api/microfilm/wasp/import/status` until the import completes.
8. `GET /api/microfilm/boxes/by-client/{clientId}` to retrieve the client's boxes and their `boxId` values.
9. `GET /api/microfilm/boxes/{boxId}` to retrieve the box plus its associated rolls.

## Endpoint reference

| Method | Route | Purpose | Request body | Response |
|---|---|---|---|---|
| `GET` | `/api/microfilm/servers` | List servers | none | `200 OK` with `servers[]` containing `serverName` and `serverId` |
| `POST` | `/api/microfilm/servers` | Create server | `{ "serverName": "Server A" }` | `200 OK`, `409 Conflict` if a server with the same name already exists |
| `GET` | `/api/microfilm/clients/{serverId}` | List clients on a server | none | `200 OK` with `clients[]` containing `jobName`, `jobNumber`, `clientId`, `serverId` |
| `POST` | `/api/microfilm/clients` | Create client on a server | `{ "jobName": "Client A", "jobNumber": "12345", "serverId": "..." }` | `200 OK`, `400 Bad Request` if `serverId` is unknown, `409 Conflict` if the client already exists |
| `POST` | `/api/microfilm/wasp/import/force` | Trigger a manual WASP import | `{ "trigger": "frontend refresh" }` | `200 OK` |
| `GET` | `/api/microfilm/wasp/import/status` | Read current or last import status | none | `200 OK` with fields such as `importEnabled`, `lastImportedAssetCount`, `lastDeferredAssetCount`, `lastIgnoredAssetCount`, `lastError`, and `lastFailureStep` |
| `GET` | `/api/microfilm/boxes/by-client/{clientId}` | List boxes for a client | none | `200 OK` with `boxes[]` containing `boxName`, `boxId`, and `clientId` |
| `GET` | `/api/microfilm/boxes/{boxId}` | Read one box and its rolls | none | `200 OK` with `box` and `rolls[]`; each roll includes `rollName`, `rollId`, and `boxId` |
| `GET` | `/api/microfilm/rows/{clientId}` | List Miller regular rows for a client | none | `200 OK` with `rows[]` |
| `POST` | `/api/microfilm/rows/{clientId}` | Create a Miller regular row | optional `{ "rowId": "...", "cells": { ... } }` | `201 Created` with `row`; `409 Conflict` if `rowId` already exists |

## Example requests

### Create a server

```http
POST /api/microfilm/servers
Content-Type: application/json

{
  "serverName": "Server A"
}
```

### Create a client for a server

```http
POST /api/microfilm/clients
Content-Type: application/json

{
  "jobName": "Client A",
  "jobNumber": "12345",
  "serverId": "SERVER_ID_FROM_QUERY"
}
```

### Force a WASP refresh

```http
POST /api/microfilm/wasp/import/force
Content-Type: application/json

{
  "trigger": "frontend refresh"
}
```

## Important notes

- Query responses use camelCase JSON.
- Query endpoints support `ETag` and `If-None-Match`, so polling clients can use conditional requests and handle `304 Not Modified`.
- For this integration, prefer `api/microfilm` over `api/inventory`. The inventory endpoints are a separate navigation surface that use composite scan IDs instead of the microfilm entity IDs.
- If you need roll details by roll ID later, there is also `GET /api/microfilm/rolls/{rollId}`.
- WASP import populates the boxes read model first. If Miller needs imported boxes as regular rows, the frontend should compare `/boxes/by-client/{clientId}` with `/rows/{clientId}` and create missing rows through `POST /api/microfilm/rows/{clientId}`.
