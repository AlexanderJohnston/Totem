Backend API contract:

- Prefer the `api/microfilm` surface, not `api/inventory`.
- The backend follows a command/query split:

  - GET endpoints return projected JSON.
- IDs are generated by the backend, so after successful create/import operations you often need to re-query to obtain the generated IDs.
- Query responses use camelCase JSON.
- Query endpoints support ETag / If-None-Match and may return 304 Not Modified.

Endpoints to use:

1. GET /api/microfilm/servers

2. POST /api/microfilm/servers

     }
   - Returns:
     - 200 OK
     - 409 Conflict if duplicate

3. GET /api/microfilm/clients/{serverId}

     - jobName
     - jobNumber
     - clientId
     - serverId

4. POST /api/microfilm/clients
   - Body:
     {
       "jobName": "Client A",
       "jobNumber": "12345",
       "serverId": "..."
     }
   - Returns:
     - 200 OK
     - 400 Bad Request if serverId is unknown
     - 409 Conflict if duplicate

5. POST /api/microfilm/wasp/import/force

     {
       "trigger": "frontend refresh"
